VCore Pawn Code is a Pawn editor for Android. It can be used to edit and develop SA-MP and open.mp scripts directly on your phone.

### Features

- Syntax highlighting
- Auto complete
- Pawn code editor
- Supports `.pwn`, `.inc`, and `.p` files
- Runs on Android devices
